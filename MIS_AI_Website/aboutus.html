What I Learned from This Assignment

Before starting this project, I had never used Visual Studio Code or created a website using HTML. I didn't initially understand how HTML operated or how various tags were used to arrange content on a webpage. I learned how to create headings, paragraphs, lists, hyperlinks, and insert images using HTML code, as I worked on the assignment. One of the biggest things I learned was the significance of using AI responsibly, especially as a college student. Another thing I learned was how cybersecurity threats, such as malware and hacking, can jeopardize personal and business information. Overall, this project improved my understanding of how technology, when used properly and securely, can benefit individuals and businesses.
